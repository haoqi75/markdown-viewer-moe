# 🚀 快速开始

<p align="left">
  <img src="/ready-to-deploy.png" alt="准备好要部署我了吗" width="220">
</p>

选择一种方式开始：

- [📥 下载编辑好的](/guide/release)：直接下载构建好的 `index.release.html`，不需要 Node.js 或 pnpm。
- [💻 本地部署](/guide/local)：克隆仓库、修改配置并自行构建，适合长期维护。
- [☁ GitHub Pages 部署](/guide/github-pages)：免费、全球可访问（国内可能较慢）。
- [☁ Codeberg Pages 部署](/guide/codeberg-pages)：和 GitHub Pages 类似，国内通常更快。

部署完成后，继续看[使用教程](/guide/use)。

::: tip 新手推荐
只想快速做一个自己的 Markdown 首页：先看[下载编辑好的](/guide/release)，改 `defaultUrl` 和 `aliases` 即可，不需要碰构建。
:::
