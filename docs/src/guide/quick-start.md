# 🚀 快速开始

<p align="left">
  <img src="/ready-to-deploy.png" alt="准备好要部署我了吗" width="220">
</p>

选择以下方式来部署程序:

- [📥 下载编辑好的](/guide/release): 直接下载构建好的文件，即使你系统没有 Node.js 或 Pnpm，也可以使用它来直接部署你的 Markdown 首页。
- [💻 本地部署](/guide/local): 强大编辑内容，随你自定义。
- [☁ GitHub Pages 部署](/guide/github-pages): 免费服务器，哪里都可以访问。（国内可能访问慢）
- [☁ Codeberg Pages 部署](/guide/codeberg-pages): 更 GitHub Pages 一样（国内可能快一点）

部署完成后可以查看[使用教程](/guide/use)。
