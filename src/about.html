🏠 返回首页 ⭐ GitHub 📖 使用文档

✨ 这是什么？

这是一个由 AI 辅助生成的萌系 Markdown 网页预览器。你只需要提供一个 Markdown 地址， 它就会把内容渲染成带目录、锚点、代码高亮、图片预览和角色插画的漂亮页面。

构建产物是单个 HTML 文件，所有 CSS、JS 和图片都会内联进去， 可以直接丢到 GitHub Pages、Codeberg Pages 或任意静态托管上使用。

💖 特色

🎀 萌系主题粉紫渐变、毛玻璃卡片、浮动装饰与标题小图标。
📑 智能目录自动提取标题，平滑滚动，滚动时同步高亮当前章节。
🔗 标题锚点支持 Markdown 内部锚点跳转，不刷新页面。
🛣️ 别名路由通过 ?p=别名 快速切换预设文档，无需改服务器。
🖼️ 图片增强相对路径自动修正、失败占位、点击毛玻璃放大预览。
💻 代码高亮集成 Prism.js，代码块美观易读。
🎨 主题切换内置粉、蓝、绿、紫、白、黄六种颜色主题。
📦 单文件交付构建后所有资源内联，部署简单到只需要一个文件。
